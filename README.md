# DeepSeek R1 vs OpenAI o3-mini API comparison

This Python script compares responses from DeepSeek R1 and OpenAI o3-mini for a given prompt. It demonstrates how to call both APIs using their respective endpoints and API keys, allowing for a direct comparison of their output quality and style.

## Language

`python`

## How to Run

1. Set your DEEPSEEK_API_KEY and OPENAI_API_KEY as environment variables.
2. Run the script: python api_comparison.py
